# SMSApplication

## About the Project

SMSApplication is an Android application developed using Java and XML in Android Studio. It is a learning project focused on Android development and SMS functionality.

## Features

* Simple Android user interface
* SMS functionality
* Java-based application logic
* XML layouts
* Android permission configuration

## Technologies Used

* Android Studio
* Java
* XML
* Android SDK

## Permissions

The application declares the following permission in `AndroidManifest.xml`:

* `android.permission.SEND_SMS`

SMS sending may also require runtime permission approval on supported Android versions. Sending messages can incur charges depending on the SIM card and mobile network.

## How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an emulator or a compatible Android phone.
